# 30 天系列架構圖

「從 MCP 到專屬 Agentic 模型」30 天鐵人賽系列所使用的架構圖，全部以 1600px 寬、白底 PNG 提供。

這個 repo 存在的唯一目的是**給文章當圖床** —— iThome 的編輯器需要可公開存取的圖片網址。

## 用法

```
https://raw.githubusercontent.com/LiuYuWei/thirty-days-diagrams/main/<路徑>
```

例如：

```
https://raw.githubusercontent.com/LiuYuWei/thirty-days-diagrams/main/01-closed-loop.png
```

## 目錄

| 路徑 | 內容 |
|---|---|
| `*.png` | 文章內的架構圖 |
| `map/` | 每一天的「今日地圖」 |
| `recap/` | 每一天的 A4 Cheat Sheet |
| `book/` | Cheat Sheet Book 的封面、階段分隔頁與跨天速查 |

圖片由 `tools/` 底下的產生器從程式碼產出，不是手繪的。
